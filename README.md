# AgriGuardian X — Vishwakarma Awards 2026–27

Engineering evidence repository for the six-wheel crop-inspection rover.

## Evidence status
- Physical rover photographs and laboratory fabrication photograph exist in the team's evidence package.
- CAD dimensions and electrical parameters in the design study are **assumptions**, not as-built measurements.
- Structural frame-grillage analysis and motor electrical transient modeling are **numerical simulations**, not certified 3D FEA, online circuit simulation, or measured hardware tests.
- Crop-diagnosis algorithm accuracy is **not verified** without a labeled evaluation dataset.

## Source package
The complete engineering source ZIP and Vishwakarma PPT are being prepared for publication. The contents should include editable OpenSCAD CAD, reproducible Python simulations, BOM, circuit topology, screenshots and image attributions.

## Responsible attribution
Only team-owned images or images with documented permission should be published. This repository distinguishes proposed, simulated, observed and independently verified claims.
